							192 text City 17 is starting to breathe.
							193 text Xenesthesia is a psychedelic visual addon for Half-Life 2. Familiar surfaces gently move, prismatic colours unfold across the world, and characters and supplies develop subtle pulses. The effects live on the materials, so they stay with the scenery as you look around.

							214 text Install
							215 text 1. Subscribe and wait for Steam to finish downloading the addon. Close Half-Life 2.
							216 text 2. In Steam Library, right-click Half-Life 2 > Properties > General > Launch Options. Add this line, keeping any existing options:
							217 text -insert_search_path "../../workshop/content/220/3826155980/workshop_dir.vpk"
							218 text 3. Launch Half-Life 2, enable Xenesthesia in its Workshop menu, and start/load the original campaign from the main menu.
							219 text This startup option loads the subscribed shaders before the game's shader cache is built. Without it, late Workshop mounting can crash the game with a shader decompression error. It uses the normal Steam library layout; custom game paths may need the absolute path to this item's workshop_dir.vpk instead. No separate download or installer is needed.
							220 text Disable conflicting material/shader addons, including City 17 ASCII, and remove any older manual Xenesthesia copy first.
							221 text Tested on the Windows 20th Anniversary version of the original Half-Life 2 using DirectX 9. Episodes, Linux and Steam Deck are not validated.
							222 text Switching it off
							223 text Close the game, remove the Xenesthesia -insert_search_path option from Steam's Launch Options, disable the addon in the Workshop menu, and restart. Remove that option before unsubscribing too. Disabling the Workshop checkbox alone will not switch off a package explicitly loaded by the launch option. No keys are rebound automatically. The developer preview's F5 live toggle uses a separate local helper; it is not included or started by this Workshop addon.
							224 text Coverage and limitations
							225 text The release covers 2,632 material definitions, with an asset audit across 68 original-campaign maps. This is broad coverage, not a promise that every surface or every scene is affected. Most transparent/additive layers, special shaders and some animated screens stay unchanged. Shared materials can animate together, and some texture/lighting seams remain visible.
							226 text Character deformation is experimental. Alyx, Kleiner, selected enemy models and Combine ragdolls received close-up checks; every character, cinematic and detail setting has not been tested. Classic zombies/headcrabs use a different lighting path. First-use shader/asset loading may still cause occasional stutters; performance varies by system and scene.
