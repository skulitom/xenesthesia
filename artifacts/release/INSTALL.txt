XENESTHESIA
Original Half-Life 2, Windows 20th Anniversary edition, DirectX 9

WORKSHOP INSTALL
Subscribe, enable Xenesthesia in the game's Workshop menu, and restart HL2.
Start/load the original campaign from the main menu. Disable conflicting material
or shader addons, including City 17 ASCII. Use only one Xenesthesia copy.

MANUAL INSTALL (alternative to Workshop)
Close HL2. Copy xenesthesia.vpk into Half-Life 2/hl2/custom, then restart.
Do not install both the manual VPK and Workshop version.

CONTROLS AND REMOVAL
No keys change automatically. Disable the Workshop addon and restart to remove
the effect. For a manual installation, close HL2 and remove xenesthesia.vpk.
The developer preview's F5 live toggle requires its separate Windows companion;
the Workshop addon does not contain or start that companion. The optional
exec xen_keys developer configuration is not needed for normal Workshop use.

LIMITS
Material coverage varies. Most transparent/additive layers, special shaders and
some animated screens remain unchanged. Shared materials can animate together.
Character pulses are experimental; complete cinematic, detail-level and campaign
regression has not been performed. Episodes and other platforms are unvalidated.
First-use shader/asset loading may cause occasional stutters.

This native addon needs no injector or replacement game executable.
