XENESTHESIA — MATERIAL COLOUR PREVIEW
Original Half-Life 2, Windows 20th Anniversary edition

Not published. Workshop upload requires the owner's explicit go.

INSTALL
1. Close HL2 and disable conflicting visual/material addons, including City 17 ASCII.
2. Open Half-Life 2's installation folder from Steam > Manage > Browse local files.
3. Copy xenesthesia.vpk into hl2/custom. Use only one Xenesthesia copy.
4. Start original Half-Life 2 and start/load from the main menu. DirectX 9 is required.

The colour and gentle movement are mapped onto supported surfaces. This revision
uses stock bloom and colour correction; the previous HDR postprocess override is gone.

CONTROLS
No keys change automatically. The developer preview has F6 pause and F8 console.
The old F4 colour toggle is retired: material effects cannot be turned off by
bypassing bloom. Optional exec xen_keys assigns F4 to console help, replacing its
previous binding. exec xen_off explains removal; it does not disable the effect.

REMOVE
Close HL2, move/delete this one VPK, then restart. For the development preview,
run tools/disable-playtest.ps1 while the game is closed. Restore preferred key
and video settings separately. If installed through Workshop later, disable it
there as well; a remaining local copy still applies.

LIMITS
Compatible surfaces, props, hands/weapons, cutouts and NPC materials receive
colour. NPCs and cutouts keep their original UVs. Authored animations are retained.
Special shaders and most translucent/additive layers and some screens are excluded.
Objects with shared materials can animate together. Classic zombies/headcrabs have an experimental geometry pulse. Alyx and selected human families also have a head/upper-body pulse. This experimental path requires Phong/bump mapping enabled; low-detail fallback and broader NPC/cinematic testing remain pending. Episodes are unvalidated.

The VPK contains material definitions, fourteen experimental compiled NPC shaders, original procedural colour data and
optional console help. It needs no injector or replacement game executable.
